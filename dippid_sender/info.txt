FILES IN 'dippid_sender'
========================

Main file (Exercise 1): DIPPID_sender.py
------------------------------------------
DIPPID input device simulator that sends accelerometer and button data
via UDP to localhost.

Additional files (Exercise 1):
--------------------------------
- DIPPID_receiver.py: minimal receiver used to verify UDP communication.
- vis_received_data.py: visualization of received sensor data (adapted 
  from demo_vis.py, provided by course).

Sample code (provided by course): DIPPID.py, demo_heartbeat.py, simple_sender.py
